Cocomomo Dashboard — Stays migration dry-run

Validates and rehearses the Phase 4 stays migration (pain point #18) against a real downloaded backup file and a throwaway/test Supabase project — mirrors how the Staff and Customers/Pets phases were rehearsed before touching live. This page never touches your live dashboard or live Supabase project; it only reads whatever backup file you pick and writes to whatever Supabase URL/key you paste in below.

Do not paste your LIVE Supabase project's URL/anon key here. Use a second/free Supabase project created just for this test, same as the previous migration phases. This tool will refuse to run if the target stays table already has any rows — same "never overwrite" safety the real migration uses — but that only protects against re-running, not against pointing this at production by mistake.
